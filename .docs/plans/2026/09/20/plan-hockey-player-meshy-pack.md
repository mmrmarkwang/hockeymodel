# Hockey player Meshy input pack

## Goal
把现有全装备球员概念图转化为一致、无干扰的 Meshy 输入参考包，并明确从生成草模到 Blender 可换装母版的交接规则。最终外观始终是穿装备的成年冰球球员，保留足够腿长，服务移动端俯视镜头。

本次为显式 AP：仅创建计划和测试场景并运行 AR；不生成新图片、不调用 Meshy、不制作模型或 Unity 代码。当前没有独立 REQ，以下从当前对话提炼的需求与验收契约作为本次规划依据；不额外启动 REQ 阶段。

### Requirement contract
- R1：参考人物穿头盔、球衣、手套、冰球裤、球袜和冰鞋，球杆独立展示；不把裸身角色作为最终设计。
- R2：提供同一人物、同一比例、同一低 A-pose 的干净正面和侧面图；图中没有文字、骨骼、重复人物、球杆或裁掉的装备。
- R3：髋、膝、踝在单独的比例检查页中标注；关节位置是设计目标，不冒充 NHL 球员实测值。
- R4：提供独立冰鞋与球杆的参考输入和描述，人物图、装备图按不同生成任务使用。
- R5：交接文档明确 jersey、skates、stick 的独立资产要求、统一比例和绑定约定，禁止把图片分区或 Meshy 提示词视为已实现模块化网格。
- R6：保留 v01 原图和来源，记录新图提示词、工具、文件路径及验证结果；明确交付的是参考包，未验证 Meshy 生成质量、动画质量或手机性能。

## Decisions
1. 保留全装备外观。主体输入使用穿齐装备但不持杆的球员，不沿用上一条“去掉冰鞋但保留脚”的默认方案。该方案直接保留用户认可的轮廓，代价是生成草模中的装备可能融合，必须在 Blender 拆件或重建。
2. 球衣暂随主体提供外观参考，独立网格由下游 Blender 提取、补边、修形和蒙皮。冰鞋与球杆另给输入参考；组装替换冰鞋时要移除主体原有冰鞋，避免重复几何。头盔、手套可在后续拆件，当前不额外扩展独立生成任务。
3. 图像生成通过内置 imagegen，以已检查的 v01 为编辑参考。先建立正面基准，再以相同角色和明确姿势约束建立侧面；如跨图漂移，针对偏差编辑，不靠多个无关重新生成结果拼成“同一人物”。
4. 主体正面与侧面统一直立低 A-pose：双臂相对躯干外展约 20–30 度、双腿适当分开、膝盖不屈成滑冰姿态。侧视图中对侧肢体允许合理遮挡；不能为了显示两只手改成另一姿势。严格侧向、正交感、无广角透视。
5. 使用全身完整构图、平整浅色背景、相同尺度与垂直基准，不以画面拉伸修正肢体比例。人物高度以头盔顶到冰刀接地线作图像对齐基准，人体比例检查另以髋/膝/踝为依据。
6. 比例记录使用归一化高度和设计目标：在最终正面图标记头盔顶、下巴、髋中心、膝中心、踝中心、刀底，记录至 proportions.md；侧面对应高度偏差目标不超过全身图高的 2%。这是图像一致性阈值，不是人体学标准或精确 3D 测量。缺少可判断位置时记录估计与不确定性，不伪造精度。
7. 移动端可读性以头盔、肩部、手套、冰鞋、球杆轮廓为优先；保持成年人体长腿比例，不添加 Q 版大头或巨型躯干。正侧图本身不能证明俯视游戏效果，下游需 Unity 相机验收。
8. 独立冰鞋展示单只完整鞋，约定左脚及其内外侧、刀架和刀刃。多视图分别保存，同一对象无左右混杂；右脚为下游镜像起点并检查非对称细节。球杆单独完整展示，默认左射杆刃方向作初始约定，不锁定以后全部角色的持杆手。
9. Meshy 模式依当前官方文档与实际界面确认：默认正面单图是必需输入；侧面先作为 Blender 校准参考，只有确认当前模式支持同物体多视图才一起提交。不得假称文字可强制分离网格，或多视图自动产生一致拓扑。主体、单鞋、球杆各自独立任务。
10. 不新增 Unity 工程、Blender 自动化、付费生成、账号配置、功能开关、环境变量、兼容层或备用生成后端；不修改已有资产。不会在 AP 内执行图片或 3D 生成。
11. 交接文档预设 Blender 尺度用米、统一对象变换和共同绑定姿势，最终身体身高由后续模型母版校准；导出坐标按实际 Unity 导入测试决定，不能把参考图当做可绑定资产。
12. 需要 E2E 场景文档，因为这些文件是外部工具的输入交接；本故事验证交付包与上传选择流程，不把付费提交、Meshy 输出、Unity 游戏性能作为本故事验收。场景见 .docs/tests/test-hockey-player-meshy-pack.md。

## Rollback / Risk
- 全部新内容写入 v02，保留 v01；撤回只需停止使用 v02，无代码/数据迁移。
- AI 正侧一致性有限；检查表与定向修订是必要步骤，无法达到阈值时记为未通过，不通过拉伸图片伪造一致。
- AI 骨骼图可能出现解剖错误；标记只作设计辅助，以人体关节位置和未来 Blender 模型校准为准。
- 全装备主体可能输出一体网格；本故事不承诺直接可换装，Blender 拆分或重建是既定后续阶段。
- 单独球鞋/球杆生成与主体可能有尺度偏差；文档记录相对尺度，下游必须校准。
- 拍摄角度、衣物遮挡会限制人体测量；不把 NHL 照片作为精确尺寸来源。
- 俯视辨识度、蒙皮变形和手机性能尚未实测；没有 Unity 工程时不把概念图标为 game-ready。
- 非 Git 目录：独立评审用文件摘要记录稳定快照，评审期间禁止修改文件，完成后重算摘要验证未变。

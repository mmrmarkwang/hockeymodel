# Hockey player Meshy input pack

## Goal
建立无装备基础人体的 Meshy 输入参考包，并明确人体、统一骨骼与独立装备的 Blender 交接规则。基础人体只穿贴身短裤，保留正常成年运动员腿长；现有全装备图保留为移动端俯视游戏的最终外观目标。

本次由显式 AR 修订既有 AP：仅更新计划和测试场景并完成架构评审；不生成新图片、不调用 Meshy、不制作模型或 Unity 代码。当前没有独立 REQ，以下从当前对话提炼的需求与验收契约作为本次规划依据；不额外启动 REQ 阶段。

### Requirement contract
- R1：主体输入为成年运动员基础人体，只穿无标志贴身短裤，赤脚、裸手；没有头盔、球衣、冰球裤、手套、护具、球袜、冰鞋或球杆。全装备 v01 仅作最终外观目标。
- R2：提供同一人物、同一比例、同一低 A-pose 的干净正面和侧面图；图中没有文字、骨骼、重复人物、球杆或裁掉的手脚。
- R3：髋、膝、踝在单独的比例检查页中标注；关节位置是设计目标，不冒充 NHL 球员实测值。
- R4：提供独立冰鞋与球杆的参考输入和描述，人物图、装备图按不同生成任务使用。
- R5：交接文档明确 Body 与 Jersey、Pants、Gloves、Helmet、Socks、Skates、Stick 分离；装备围绕同一人体母版适配，定义各部件制作来源、统一比例和骨骼约定，不依赖从全装备主体拆件。不得把提示词当作已实现的模块化网格。
- R6：保留 v01 原图和来源，记录新图提示词、工具、文件路径及验证结果；明确交付的是参考包，未验证 Meshy 生成质量、动画质量或手机性能。

## Decisions
1. 主体输入改为无装备基础人体，仅穿贴身短裤，赤脚裸手，成年运动员身材。v01 只保留人物身份、风格与最终装备外观参考；不能把护肩宽度当裸肩宽度，或沿用装备造成的身体体积。无需制作生殖器细节。
2. 下游先校准基础人体并建立标准骨骼，再围绕它制作 Jersey、Pants、Gloves、Helmet、Socks；球衣与裤子可由人体表面派生并补足衣物/护具厚度，头盔和手套独立建模适配。Skates、Stick 使用本包独立参考生成草模后适配。本故事不制作装备网格，也不要求这些装备全都交给 Meshy 生成。
3. 图像生成通过内置 imagegen，以已检查的 v01 为身份与风格参考，重新建立无装备人体。先建立正面基准，再以相同角色和明确姿势约束建立侧面；如跨图漂移，针对偏差编辑，不靠多个无关重新生成结果拼成“同一人物”。
4. 主体正面与侧面统一直立低 A-pose：双臂相对躯干外展约 20–30 度、双腿适当分开、膝盖不屈成滑冰姿态。侧视图中对侧肢体允许合理遮挡；不能为了显示两只手改成另一姿势。严格侧向、正交感、无广角透视。
5. 使用全身完整构图、平整浅色背景、相同尺度与垂直基准，不以画面拉伸修正肢体比例。人物高度以无头盔的头顶到赤脚脚底接地线作图像对齐基准，人体比例检查另以髋/膝/踝为依据。
6. 比例记录使用归一化高度和设计目标：在最终正面图标记头顶、下巴、髋中心、膝中心、踝中心、脚底，记录至 proportions.md；侧面对应高度偏差目标不超过全身图高的 2%。这是图像一致性阈值，不是人体学标准或精确 3D 测量。缺少可判断位置时记录估计与不确定性，不伪造精度。
7. 移动端可读性以头盔、肩部、手套、冰鞋、球杆轮廓为优先；保持成年人体长腿比例，不添加 Q 版大头或巨型躯干。正侧图本身不能证明俯视游戏效果，下游需 Unity 相机验收。
8. 独立冰鞋展示单只完整鞋，约定左脚及其内外侧、刀架和刀刃。多视图分别保存，同一对象无左右混杂；右脚为下游镜像起点并检查非对称细节。球杆单独完整展示，默认左射杆刃方向作初始约定，不锁定以后全部角色的持杆手。
9. Meshy 模式依当前官方文档与实际界面确认：默认正面单图是必需输入；侧面先作为 Blender 校准参考，只有确认当前模式支持同物体多视图才一起提交。不得假称文字可强制分离网格，或多视图自动产生一致拓扑。主体、单鞋、球杆各自独立任务。
10. 不新增 Unity 工程、Blender 自动化、付费生成、账号配置、功能开关、环境变量、兼容层或备用生成后端；不修改已有资产。不会在 AP 内执行图片或 3D 生成。
11. 交接文档预设 Blender 尺度用米、统一对象变换和共同绑定姿势，最终身体身高由后续模型母版校准；基础人体不包含冰鞋抬高量，穿鞋后另校准刀底接触面。基础人体网格与 Unity Humanoid 骨骼映射是不同交付阶段；导出坐标按实际 Unity 导入测试决定，不能把参考图当做可绑定资产。
12. 需要 E2E 场景文档，因为这些文件是外部工具的输入交接；本故事验证交付包与上传选择流程，不把付费提交、Meshy 输出、Unity 游戏性能作为本故事验收。场景见 .docs/tests/test-hockey-player-meshy-pack.md。

## Rollback / Risk
- 全部新内容写入 v02，保留 v01；撤回只需停止使用 v02，无代码/数据迁移。
- AI 正侧一致性有限；检查表与定向修订是必要步骤，无法达到阈值时记为未通过，不通过拉伸图片伪造一致。
- AI 骨骼图可能出现解剖错误；标记只作设计辅助，以人体关节位置和未来 Blender 模型校准为准。
- 无装备人体仍可能有手指融合、关节拓扑或比例问题，不能直接当作可绑定生产资产；Blender 清理、重拓扑与变形验证是后续必需阶段。装备单独制作仍需尺寸与权重适配。
- 单独球鞋/球杆生成与主体可能有尺度偏差；文档记录相对尺度，下游必须校准。
- 拍摄角度、衣物遮挡会限制人体测量；不把 NHL 照片作为精确尺寸来源。
- 俯视辨识度、蒙皮变形和手机性能尚未实测；没有 Unity 工程时不把概念图标为 game-ready。
- 独立评审记录 Git 工作区状态与文档摘要，评审期间禁止修改文件，结束后重算摘要。AR 不自动提交或推送；文档修改可用 Git 单独查看或撤回。

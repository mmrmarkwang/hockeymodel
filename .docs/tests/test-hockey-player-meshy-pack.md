# E2E — hockey-player-meshy-pack
本故事验证本地参考包与外部工具输入交接。AP/AR 只编写或修订场景，不执行。无需登录、付费提交或 Meshy 生成。下游 3D、Unity 与手机测试不在本故事验收内。

## Scenario 1 — 无装备基础人体输入
打开 v02/body-front.png 和 body-side.png。
预期：每张仅一个完整人物，均为成年运动员，只穿贴身短裤，赤脚裸手；没有头盔、球衣、冰球裤、手套、护具、球袜、冰鞋或球杆，无文字、骨骼或重复人物。两个视图统一低 A-pose、身体比例、肤色与短裤外观；侧面遮挡符合相同三维姿态。
证据：图像预览、人工检查结果，发现异常则修订后重检。

## Scenario 2 — 比例一致性
对照 proportions.md 和 proportion-check.png，按人物无头盔头顶到赤脚脚底高度归一化正侧关键点。
预期：髋中心位于贴身短裤覆盖的骨盆位置，膝踝可见；大腿与小腿比例合理，不沿用装备体积推断裸身体积。正侧对应高度误差不超过全身高度 2%，标记注明设计估计。
证据：正侧关键点坐标/归一化高度/差值表。模糊或估计位置明确说明，不以假精度通过；无法判断则未通过。

## Scenario 3 — 三个独立生成任务
仅依据 meshy-inputs.md，为人物、单只冰鞋、球杆各列上传文件。
预期：人物默认 body-front.png；冰鞋默认 skate-left-side.png；球杆默认 stick.png。各任务恰好一个主图。侧面与鞋斜视图是否可上传由当前模式文档决定；未确认时只作建模参考。不能上传 v01 整页、proportion-check.png 或混合不同物体。
证据：本地任务到文件映射与当次核实的官方文档链接；不需要真实提交。
检查每项英文描述与图像一致，人物必须写明仅穿贴身短裤、赤脚裸手、无冰球装备，单鞋不得误称一双。

## Scenario 4 — 模块化交接边界
阅读 blender-handoff.md。
预期：Body 与 Jersey、Pants、Gloves、Helmet、Socks、Skate_L/Skate_R、Stick 分离；逐项定义人体派生、独立建模或草模适配来源，按人体/标准骨骼→装备适配顺序执行。明确尺寸与姿势校准、短裤/被遮挡人体处理、裸脚入鞋与刀底接触面、蒙皮和握持点步骤；不声称提示词已实现这些结果。
证据：逐项文档路径与小节映射。缺少部件策略即未通过。

## Scenario 5 — 文件与追溯
列出 v02 文件，检查图片可打开、正侧画布一致、README 链接有效、完整提示词存在，比较实施前后 v01 摘要。
预期：v01 无变化，新资源只在 v02；来源表述与实际工具输入一致；所有验证结果真实标明执行/未执行，明确未交付 3D 模型、动作或手机性能验证。
证据：文件清单、尺寸输出、摘要、validation.md。

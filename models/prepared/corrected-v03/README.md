# Revision 03 — knee fullness and reference grip

This is a new review candidate; revision 02 and all originals remain intact.

## Knees

The rest mesh now has a smoothly tapered increase in width and depth around the knees. In the sampled knee band, width increased from approximately 11.6–11.7 cm to 14.6–14.8 cm. The front of the knee also received a small depth adjustment. This is an intentional stylized proportion adjustment for review, not an anatomical measurement from a player.

The v02 joint pivots, forward-bending pose solution and smooth skin-weight transitions are retained. Vertex/triangle counts remain 9,000/18,000. Standing and squat front/side renders are supplied. No production retopology was performed; rear compression and surface detail still require review.

## Grip

Visual target: the user-approved image at repository path `design/characters/player-v02/approved/left-shot-grip-approved.png`.

`stance/hockey-grip-v03.blend` contains actual 3D replacement gloves and a diagonal, raised-stick pose. Revision 02 is not the approved grip. This revision rebuilds continuous curled fingers, a compact padded hand back, contrasting palm leather, and the lower-left thumb on the blade-side index edge. It preserves the reference's right-hand back / left-hand palm presentation and the separate wrist/elbow solve.

These are still static blockout gloves, not articulated fingers or production equipment. The user-approved concept image does not imply approval of this 3D revision. Exact silhouette/contact and wrist anatomy must be judged in the new rendered closeup. Neither this equipment scene nor mobile performance has been validated in Unity.
